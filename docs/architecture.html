01 / THE THESIS

Reuse the execution system—not a taxonomy of wrappers.

AgentRig standardizes how heterogeneous work is composed, observed, graded, and controlled. It preserves the semantics of the things doing that work.

The central design statement

Workflows depend on typed capabilities. Integrations bind runtimes and providers to those capabilities.
Avoid

Wrappers around wrappers

Vendor SDK↓ Service wrapper↓ Platform wrapper↓ Universal agent

This hides meaningful differences and creates boilerplate before reuse exists.

Build

Narrow contracts, shared execution

Typed capability↕ Direct or agent-backed integration+ Workflow · events · grades · evals

The reusable infrastructure surrounds execution without flattening every system into one API.

Design emphasis

Where reuse is expected to compound

The highest-leverage reuse is operational: context, lifecycle, artifacts, grading, and evaluation. Vendor wrappers matter, but they are not the center of gravity.

04 / COMPOSITION MODEL

Workflows are values assembled in Python.

Configuration changes are composition. New portable behavior implements a protocol. Subclassing is the narrow exception.

Graded implementation workflow
# Ordinary Python is the workflow language.
workflow = Sequence(
  FunctionStep(select_task),
  GradeStep(
    graders=scope_graders,
    policy=scope_policy,
  ),
  AgentStep(implementer),
  ProcessStep(validations),
  AgentStep(reviewer),
  RepairLoop(
    agent=implementer,
    graders=quality_graders,
    max_attempts=2,
  ),
)

outcome = await workflow.run(
  task,
  context=run_context,
)
Anatomy

Five separable decisions

No workflow subclass is necessary. Each policy and implementation can change independently.

05 / THEORY OF OPERATION

A run is a correlated tree of typed decisions.

Every step receives context, performs bounded work, produces observable evidence, and returns an explicit outcome.

Run lifecycleRepeat inside child contexts as needed
01ComposeApplication wires integrations, agents, graders, and policies.
02ContextualizeCreate root context, then derive a child context per step.
03ExecuteInvoke function, capability, agent, or approved process.
04ObserveTranslate events, usage, errors, and artifact lineage.
05GradeEvaluate evidence and apply deterministic grade policy.
06DecideContinue, warn, repair, request approval, or block.
07RepairCreate a targeted request; preserve passing constraints.
08ConcludeReturn typed outcome, artifacts, grades, and trace reference.
09EvaluateRepeat over versioned cases when running an eval suite.
10CompareAggregate, baseline, and make a deterministic promotion decision.
Retry ≠ repairRetry repeats the same operation after a classified transient technical failure. It must respect side effects.
Repair changes the requestRepair uses grader evidence to produce a new, targeted attempt after a valid but unacceptable result.

No score laundering

A hard fidelity failure cannot be averaged away by an aesthetic score.

No hidden authority

An LLM judge can report a grade. It cannot grant permission or silently authorize a side effect.

07 / OBSERVABILITY

Core owns the trace contract—not the telemetry vendor.

A stable run tree makes workflows diagnosable while redaction and references keep private content out of telemetry by default.

Events describe execution without becoming a data leak.

Concrete exporters—console, JSONL, OpenTelemetry, or vendor sinks—consume the same core event contract.

RRecord stable IDs, timings, status, and sanitized metadata.
↗Reference large or private artifacts instead of copying them into events.
×Never log credentials, raw user media, or complete provider responses by default.
VVersion event payloads and grader records for later interpretation.

09 / APPLICATION BOUNDARY

AgentRig enables your application. It does not absorb it.

This boundary keeps AgentRig reusable while domain meaning, invariants, and product behavior remain authoritative in the consuming application.

AgentRig owns

Generic execution mechanics

Reusable infrastructure with no knowledge of stories, characters, pages, or canonical world state.
